Política de Privacidade

Última atualização: 21 de abril de 2026

Esta Política de Privacidade descreve como Leo Braga Marketing ("nós", "nossa empresa") coleta, usa, armazena e protege as informações acessadas por meio do aplicativo leobraga-mkt, integrado à API de Marketing do Facebook/Meta.

1. Sobre o Aplicativo

O aplicativo leobraga-mkt é uma ferramenta de uso interno utilizada exclusivamente por Leo Braga Marketing para gerenciar campanhas de anúncios em plataformas Meta (Facebook e Instagram) em nome de clientes que contrataram nossos serviços de gestão de tráfego pago.

2. Dados Acessados

Para executar as operações de gestão de campanhas, o aplicativo acessa as seguintes informações por meio das permissões concedidas pelo usuário:

  • Informações de contas de anúncios (IDs, nomes, status e configurações)
  • Campanhas, conjuntos de anúncios e anúncios (incluindo criativos, segmentação e orçamentos)
  • Métricas e relatórios de desempenho (impressões, cliques, conversões, gastos)
  • Páginas do Facebook vinculadas às contas de anúncios
  • Informações de contas do Instagram associadas
  • Públicos personalizados e semelhantes (lookalike)

3. Finalidade do Uso dos Dados

Os dados acessados são utilizados exclusivamente para:

  • Criar, editar, pausar e ativar campanhas e anúncios em nome dos clientes
  • Gerar relatórios de desempenho e análises de resultados
  • Otimizar campanhas com base em métricas de performance
  • Realizar auditorias e diagnósticos de contas de anúncios

Nenhum dado é vendido, compartilhado com terceiros ou utilizado para fins publicitários próprios.

4. Armazenamento e Segurança

Os dados acessados pela API são processados localmente e não são armazenados em servidores externos. Tokens de acesso e credenciais são mantidos em arquivos de configuração locais protegidos, com acesso restrito ao operador autorizado da ferramenta.

Adotamos as seguintes medidas de segurança:

  • Tokens de acesso armazenados apenas localmente, nunca em serviços de terceiros
  • Acesso à ferramenta restrito ao operador responsável pela conta
  • Não há banco de dados externo ou armazenamento em nuvem das informações obtidas pela API

5. Retenção de Dados

As informações acessadas via API são utilizadas em tempo real para execução das operações solicitadas. Relatórios gerados são mantidos apenas pelo período necessário para prestação de contas ao cliente contratante, e eliminados após o encerramento da relação contratual.

6. Compartilhamento de Dados

Os dados acessados não são compartilhados com terceiros, exceto quando exigido por lei ou por determinação judicial.

7. Direitos do Usuário

Os titulares das contas de anúncios mantêm controle total sobre seus dados. A qualquer momento, o usuário pode:

  • Revogar o acesso do aplicativo por meio das Configurações de Privacidade do Facebook
  • Solicitar a exclusão de quaisquer dados associados ao uso do aplicativo
  • Solicitar informações sobre quais dados foram acessados

8. Uso da API Meta (Facebook)

Este aplicativo utiliza a API de Marketing do Meta em conformidade com os Termos de Serviço da Plataforma Meta para Desenvolvedores e a Política de Dados do Facebook.
